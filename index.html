开始你的第一次分析

  1. 先试用示例。加载浏览器 Python 环境后，程序生成模拟干涉图并实际进行 SBAS 反演。模拟成果会清楚标记。
  2. 导入自己的 NPZ 栈。使用完整 Python 程序的 save_stack 函数导出，或按下面格式准备。
  3. 设置参考点与相干性。点击开始，完成后查看分布图、选点时序并下载结果。

NPZ 输入格式

dates: [N]，YYYYMMDD，按时间排序
pairs: [M,2]，两期日期
values: [M,行,列]，已解缠相位
coherence: [M,行,列]，0～1
unit: "radian" | "mm" | "m"
wavelength_m: 雷达波长（米）
phase_sign: -1 或 +1

可选：mask、components、JSON 字符串 metadata。弧度数据的位移换算为 phase_sign × λ × phase / (4π)。默认 Sentinel-1 波长约 0.05547 m、符号 -1；真实数据需要确认。NPZ 不允许 pickle 对象数组。

适用范围

网页提供逐像元加权网络反演和拟合诊断；不进行大气、轨道、残余 DEM 或解缠错误改正。输入需预先配准、解缠并统一网格。图上的坐标为行列号，NPZ 导出保留源 metadata。

文件只在浏览器内处理，不上传影像。页面刷新或停止计算会清除计算会话。大数据受浏览器内存限制，文件上限 25 MiB、最多 36 期和 160 个干涉对，影像行列各不超过 512；解压大小、工作内存和计算量还会进行检查。

原始 SLC 到干涉栈的处理请使用完整 Python 程序连接 ISCE2 / MintPy；当前网页未连接云计算服务器。
